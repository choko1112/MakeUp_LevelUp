# Vercelで500エラーが出たときの確認ガイド

この資料は、MakeUp_LevelUpをVercelで公開したときに発生した500エラーと、その解決方法をまとめたものです。

## 500エラーとは

500エラーは、ブラウザからのお願いを、Webサイト側でうまく処理できなかったときに表示されるエラーです。

今回の場合は、Vercelの中でWebサイトを動かすために必要な道具が足りず、サイトが起動できませんでした。

## Webサイトが表示されるまでの流れ

```text
ブラウザでVercelのURLを開く
          |
          v
VercelがGitHubのコードを受け取る
          |
          v
必要な道具を準備する
FastAPI / Jinja2 / Uvicorn
          |
          v
main.pyを読み込んでサイトを起動する
          |
          v
HTMLをブラウザに返す
          |
          v
Webサイトが表示される
```

GitHubはコードを保管する場所、Vercelはコードをインターネット上で動かす場所、ブラウザはサイトを見るための道具です。

## 今回、止まっていた場所

Vercelのログには、次のエラーが表示されていました。

```text
ModuleNotFoundError: No module named 'fastapi'
```

これは「FastAPIという、サイトを動かすための道具が見つからない」という意味です。

`main.py`には、最初にFastAPIを使う宣言があります。

```python
from fastapi import FastAPI, Request
```

しかし、Vercelの中にFastAPIが準備されていなかったため、`main.py`を読み込む途中で止まりました。

```text
Vercel
  |
  v
main.pyを読む
  |
  v
FastAPIを使おうとする
  |
  x
FastAPIが見つからず停止
```

そのため、トップページだけでなく、動作確認用の `/api/health` も500になりました。

## `/api/health` とは

`/api/health` は、Webサイトが起動しているか確認するための試験用ページです。

```python
@app.get("/api/health")
async def health_check() -> dict[str, str]:
    return {"status": "ok"}
```

ブラウザで次のURLを開きます。

```text
https://あなたのVercelドメイン.vercel.app/api/health
```

正常な場合は、次の表示になります。

```json
{"status":"ok"}
```

## 解決方法

Vercelに必要な道具を準備してもらうため、`pyproject.toml`に依存関係を追加しました。

```toml
[project]
name = "steplog"
version = "0.1.0"
description = "A self-improvement dashboard built with FastAPI"
requires-python = ">=3.12"
dependencies = [
    "fastapi==0.116.1",
    "jinja2==3.1.6",
    "uvicorn[standard]==0.35.0",
]
```

| 道具 | 役割 |
| --- | --- |
| FastAPI | WebサイトやAPIを動かす本体 |
| Jinja2 | HTMLテンプレートを表示する道具 |
| Uvicorn | FastAPIを動かすサーバー |

ローカルのパソコンに道具が入っていても、Vercelは別の実行環境です。Vercelにも必要な道具を伝える必要があります。

## 途中で発生した別の問題

### `vercel.json`の書き方

`includeFiles`は配列ではなく、文字列で指定する必要があります。

```json
"includeFiles": "{templates/**,static/**}"
```

これは、HTMLのテンプレートやCSS、JavaScriptをVercel側でも使えるようにする設定です。

### 静的ファイル収集の警告

```text
FastAPI static file collection failed.
Static files will not be served from the CDN.
```

これは、`static/`フォルダのCSSやJavaScriptを高速配信用の場所に移せなかったという警告です。今回の500エラーの直接原因は、FastAPIが見つからなかったことでした。

## 今後の確認手順

1. VercelのBuild Logsで、設定やインストールの失敗を確認する。
2. VercelのRuntime Logsで、実際にサイトを開いたときのエラーを確認する。
3. `/api/health`を開き、`{"status":"ok"}`が表示されるか確認する。
4. `ModuleNotFoundError`、`ImportError`、`FileNotFoundError`、`TemplateNotFound`などの行を探す。

## 確認結果の見方

| 結果 | 意味 |
| --- | --- |
| `{"status":"ok"}` | FastAPIは起動している |
| 500 | 起動や必要な道具に問題がある可能性が高い |
| 404 | URLや入口の設定に問題がある可能性が高い |

ログの最後に`/favicon.ico`と表示されても、それが原因とは限りません。今回も、本当の原因は次のエラーでした。

```text
ModuleNotFoundError: No module named 'fastapi'
```
